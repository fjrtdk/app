# Plan 01-01: Firebase Project Setup

## Objective

Create a Firebase project with Google sign-in enabled, generate service account credentials, and configure environment variables for both backend and frontend.

## Context

Phase 1 is pure setup — no code changes to the app. The Firebase project, service account key, and web SDK config are prerequisites for Phases 2-4.

## Tasks

### Task 1: Create Firebase project and enable Google Auth

<read_first>
- .planning/phases/01-firebase-project-setup/01-CONTEXT.md
</read_first>

<action>
1. Install firebase-tools: `npm install -g firebase-tools`
2. Log in to Firebase: `firebase login`
3. Create Firebase project: `firebase projects:create prompt-optimizer`
4. Set default project: `firebase use prompt-optimizer`
5. Enable Google Auth in Firebase Console (web UI):
   - Go to https://console.firebase.google.com
   - Open project → Authentication → Sign-in method
   - Enable Google provider
   - Configure OAuth consent screen if needed
   - Add `http://localhost:3000` to authorized domains for dev
6. Register web app: `firebase apps:create web prompt-optimizer-web`
7. Get Firebase Web SDK config: `firebase apps:sdkconfig web`
</action>

<acceptance_criteria>
- `firebase projects:list` shows `prompt-optimizer`
- Google sign-in is enabled in Firebase Console
- Web SDK config is available (API key, authDomain, projectId, etc.)
</acceptance_criteria>

### Task 2: Generate and download service account key

<read_first>
- Task 1 (Firebase project must exist first)
</read_first>

<action>
1. Go to Firebase Console → Project settings → Service accounts
2. Click "Generate new private key"
3. Download JSON file to secure location (e.g., `~/.credentials/prompt-optimizer-firebase-admin.json`)
4. Extract the following values from the JSON:
   - `project_id` → FIREBASE_PROJECT_ID
   - `client_email` → FIREBASE_CLIENT_EMAIL
   - `private_key` → FIREBASE_PRIVATE_KEY
</action>

<acceptance_criteria>
- Service account JSON file exists at specified location
- `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` are extractable
- JSON is NOT in the repo (verify NOT in backend/ or frontend/ directories)
</acceptance_criteria>

### Task 3: Write backend .env file

<read_first>
- backend/.env (existing file — read to preserve any existing vars)
- Task 2 (service account values needed)
</read_first>

<action>
Edit `backend/.env` to add Firebase vars. Read the existing file first and preserve any existing variables (MONGO_URL, DB_NAME, NIM_API_KEY, NIM_BASE_URL, NIM_MODEL, CORS_ORIGINS). Add:

```
FIREBASE_PROJECT_ID=prompt-optimizer
FIREBASE_CLIENT_EMAIL=<from service account JSON>
FIREBASE_PRIVATE_KEY="<from service account JSON — wrap in double quotes for multiline>"
```
</action>

<acceptance_criteria>
- `backend/.env` contains `FIREBASE_PROJECT_ID=prompt-optimizer`
- `backend/.env` contains `FIREBASE_CLIENT_EMAIL=`
- `backend/.env` contains `FIREBASE_PRIVATE_KEY=`
- Existing vars (MONGO_URL, DB_NAME, etc.) are preserved
- `.env` is in `.gitignore` (already should be)
</acceptance_criteria>

### Task 4: Write frontend .env.local file

<read_first>
- Task 1 (Firebase Web SDK config needed)
</read_first>

<action>
Create `frontend/.env.local` with Firebase Web SDK config:

```
REACT_APP_FIREBASE_API_KEY=<from Web SDK config>
REACT_APP_FIREBASE_AUTH_DOMAIN=prompt-optimizer.firebaseapp.com
REACT_APP_FIREBASE_PROJECT_ID=prompt-optimizer
REACT_APP_FIREBASE_STORAGE_BUCKET=prompt-optimizer.appspot.com
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=<from config>
REACT_APP_FIREBASE_APP_ID=<from config>
```
</action>

<acceptance_criteria>
- `frontend/.env.local` exists
- Contains all 6 `REACT_APP_FIREBASE_*` vars with real values
- `.env.local` is in `frontend/.gitignore` (already should be)
</acceptance_criteria>

## Verification

- `firebase projects:list` shows the project
- Backend `.env` has Firebase vars and loads without errors
- Frontend `.env.local` has Firebase config
- Service account JSON is outside the repo
