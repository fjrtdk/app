# Plan 02-01: Firebase Admin Integration

## Objective

Add firebase-admin SDK, initialize Firebase in server.py, create a verify_firebase_token helper, and add POST /api/auth/firebase endpoint.

## Tasks

### Task 1: Add firebase-admin to requirements.txt
- Added `firebase-admin==7.4.0`

### Task 2: Firebase Admin initialization in server.py
- Load `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` from env
- Initialize with `credentials.Certificate(dict)` if all 3 vars present

### Task 3: POST /api/auth/firebase endpoint
- Accept `{ "id_token": "..." }`
- Verify with `firebase_auth.verify_id_token()`
- Get full profile via `firebase_auth.get_user(uid)` if available
- Create/update user doc in MongoDB
- Generate session token, store in user_sessions
- Set httpOnly session cookie
- Return user data

## Verification

- `python3 -m py_compile backend/server.py` passes
- curl POST /api/auth/firebase returns appropriate errors for missing/expired tokens
- curl POST /api/auth/firebase with valid Firebase ID token creates user + session
